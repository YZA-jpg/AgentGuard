# 护栏复现的困难与失败案例

2026-11-26。实验对象为 SafetyDrift 固定 72 条、ATBench 配对留出 200 条，以及 AgentDojo Pro 固定轨迹。

## 复现卡在哪里

- **缺少逐项可对齐的作者资产。** 还未核实 DreamGuard 清理后的样本 ID、最终 Scheme-D 设置及论文 TRACES 基线的确切检查点和阈值。本地 DreamGuard 与新版 TRACES 已对齐训练、校准和测试 ID（221/57/72）。分类 F1 分别为 97.44% 和 97.30%，论文报告 96.4% 和 87.1%。[DreamGuard 论文表 1–2 与附录 C](https://arxiv.org/html/2608.05695v1)
- **SafetyDrift 的轨迹分类容易被捷径抬高。** 训练监督前缀中，没有任何工具同时有即时安全和危险标签。训练集学出的工具名规则在测试集 F1=100%，严格提前检出率 PHIR=0%。两组的 F1 接近时，仍需看各自何时预警。
- **跨数据集的输入和指标不同。** SafePred-8B 在 SafetyDrift 两次复测的 F1 都是 21.28%。DreamGuard 在 ATBench 200 条上误拦 101/101 条安全轨迹，目标域重新校准后 FPR 为 8.91%，Recall 也降到 6.06%。AgentDojo 固定回放测量干预，在线 ASR 和任务完成率需要执行后续轨迹才能测量。

## 值得验证的方法假设

把**当前动作的可验证副作用**与**此前风险是否仍未解除**分开建模。状态只从执行前可见的观测更新，记录被访问的数据或资源、授权范围、相关证据的来源，以及是否已有明确的清理或恢复动作。候选工具的副作用以工具定义和当前参数为依据。然后用两个输出分别判断当前动作是否会产生越权效果，以及历史风险是否已经累积到需要复核。任务偏离可单独给提示，是否升级为拦截由已确认的安全后果决定。

最小验证做三项消融：可见历史状态、工具副作用、风险证据的清除机制。先用独立开发集做配对。一组固定工具和动作形式，只改授权或已观察到的前缀；另一组固定任务和前缀，比较只读辅助动作、可逆写入与不可逆副作用。用人工复核或模拟器判定安全标签。旧测试案例用于提出假设，不用于选择阈值或构造配对模板。最后在固定 SafetyDrift 72 条上评估 F1、Recall、FPR、PHIR、MAS 和端到端延迟，并单报新配对集的正确排序率与误拦率。恢复动作 FPR 只在有独立恢复标签时计算。
